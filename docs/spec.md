# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

スマホの縦画面を親指1タップで遊ぶ、積み上げ系の30秒〜1分のバズるWebゲーム。結果は称号つきのスクショ映えする画面で共有できる。（元のメモ：スマホで流れてきて思わず遊んでシェアしたくなる、バズる Web ゲーム（ジャンルはおまかせ））

## 前提

- 使う人・使う場面（デザイン担当の分析。推定を含む）：
  - 使う人：X・Instagram・TikTok でリンクや結果のスクショが流れてきて、思わずタップした人。説明は読まない
  - 使う場面：電車や休み時間に、スマホを縦に持って親指1本で30秒〜1分。負けたらすぐ「もう一回」
  - 遊んだあと：称号つきの結果の画面をスクショするか「結果をシェア」で友だちに送り、相手も同じURLで挑む
  - PC では、スペースキーかクリックで同じ遊び方ができる
  - ゲームパッド（standard マッピング）の A ボタンは、スペースキーと同じ。タイトルでスタート、遊ぶ間は積み木を止める、結果で「もう一回」（結果が出た直後 0.45 秒の誤タップ防止ロックも同じく効く）。押し始めの1回だけ反応し、押しっぱなしでは連打にならない。複数つながっていれば、どれの A でも反応する。パッドが無い環境では何も起きない。音は最初の押下から鳴らし始める。画面の文言（「スペースキーでも遊べます」など）は変えず、パッド専用の案内は出さない
- 技術：TypeScript・Vite（Canvas／WebGL）、テストはVitest。Vercel で公開する（スマホ・PC のブラウザで遊ぶ）

## 遊びの決まり

数字はコードの今の値（`src/lib/stack.ts`・`src/lib/result.ts`・`src/game.ts`・`src/main.ts`）。変えるときは、コードと一緒にここも直す。

### 時間

- 30秒で始まる（`TIME_START`）。0になると「タイムアップ！」で終わる
- ピッタリするたびに +1秒（`PERFECT_BONUS`）。上限は無い
- 時計は実際の時間で進む。タブが隠れている間は止まる（戻っても、隠れていた分は足さない）
- 終わってから結果の画面に出るまでの 1.25 秒は、時計も止まる

### 重ねる

- 動く積み木は、中心から左右 ±160 単位の間を行き来する（`SWING`）
- 速さは `min(560, 170 + 階 × 11)` 単位/秒（`speedFor`）。階が上がるほど速くなり、560 で止まる
- 積み木は左右の端から交互に出る
- 1階 = 3m（`METERS_PER_FLOOR`）。地面の上に積めた数が「階」。土台は数えない

### ピッタリとずれ

- 上の積み木との中心のずれが 5 単位以下なら「ピッタリ」（`PERFECT_TOLERANCE`）。上の積み木に揃えて置く
- 連続ピッタリ（`combo`）は、ピッタリするたびに +1。ずれると 0 に戻る
- 3連続ピッタリ目から、ピッタリするたびに幅が +8 戻る（`COMBO_GROW`）。上限は最初の幅 220（`BASE_WIDTH`）。1・2連続目は幅が変わらない
- ずれたときは、はみ出した分が切れて落ちる。塔に残るのは重なった部分だけ
- 重なりが 0.5 単位以下になると、積み木は全部落ちて終わり（落っこちた！）

### 称号とひとこと（`src/lib/result.ts`）

- 称号の段（階数）：0〜3階「地面とお友だち」、4〜8階「ひよっこ積み師」、9〜14階「屋上の住人」、15〜21階「雲をつかむ人」、22〜29階「空の大工」、30〜39階「成層圏の棟梁」、40階以上「宇宙まで積んだ人」
- 頭に付く言葉は、3階以上のとき、次の上から最初に当たる1つ（当たらなければ付かない）
  1. ピッタリの割合（ピッタリ回数 ÷ 階数）が 0.6 以上：「ピタ止めの」
  2. 最大連続が 6 以上：「連続ピタッの」
  3. 落っこちて終わり、かつ 15階以上：「あと一歩の」
  4. 最後に残った幅が 220 の 25% 未満：「綱渡りの」
  5. 1秒あたりの階数が 1.1 以上：「早押しの」
- ひとこと（上から最初に当たるもの）
  1. 0階：「1段目で落っこちた。次はいける」
  2. 最大連続が 4 以上：「最大 N 連続ピタッ！」
  3. 最後に残った幅が 25% 未満：「最後は幅 N% で耐えた」
  4. 高さが 5m 以上：「キリン X 頭ぶんの高さ」（5m 単位、小数第1位で切り捨て）
  5. それ以外：「ピタッ N 回」

### 記録

- 一番いい記録（ベストの階数）は、ブラウザの localStorage の `tap-stack-rush:best` に覚える。その回が今のベストより多い階数で終わったときだけ更新し、結果に「ベスト 更新！」を出す
- 消音は `tap-stack-rush:mute` に覚える（`"1"` が消音、`"0"` が出す）。音のボタンと M キーで切り替える

### 操作

- タイトルで始める：タップ・クリック・スペース・Enter・↑・↓（ゲームパッドの A も。「前提」の、ゲームパッドの決まりを参照）
- 遊ぶ間に置く：タップ・クリック・スペース・Enter・↑・↓
- 結果の画面：R か、スペース・Enter で「もう一回」（ボタンにフォーカスがあるときは、そのボタンの動き）。S で共有。画面のタップでは何も起きない
- 結果が出てから 0.45 秒は、「もう一回」（R・スペース・Enter・ボタン・ゲームパッドの A）が効かない。共有と消音は効く
- M キーで、どの画面でも音を消す・出す

### 共有

- 「結果をシェア」か S で、結果の画面を PNG（`tap-stack-rush.png`）にして、文と一緒に Web Share で送る。画像を付けられないときは、文だけを送る
- 文：「TAP STACK RUSH で ◯階（◯m）積んだ！」・「称号「◯」」・ひとこと・今のページの URL
- Web Share が無いとき、または失敗したとき（キャンセルは除く）は、文をクリップボードに写す。写せたらトースト「結果の文をコピーしました」、写せなければ「コピーできませんでした」
