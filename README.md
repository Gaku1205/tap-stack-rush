- 仕様：[docs/spec.md](docs/spec.md)
- 見た目：[docs/design.md](docs/design.md)

[ai-dev-template](https://github.com/Gaku1205/ai-dev-template) の工場で、1行のメモ（スマホで流れてきて思わず遊んでシェアしたくなる、バズる Web ゲーム（ジャンルはおまかせ））から作ったサービスです。Issue を書くと、AI が清書・実装・レビュー・マージまで進めます（[docs/pipeline.md](docs/pipeline.md)）。
