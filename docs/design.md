# デザイン仕様

画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。

## 考え

**一色刷りのポスターの上に、ぷっくりした積み木が空まで積み上がっていく。**

- 背景はいつも1色のベタ（＋薄い放射の帯）。模様・写真・グラデの面は使わない
- 形は全部「墨の輪郭＋ベタ塗り＋下にずらした墨の影」のシール風。どんな背景の上でも絵が負けない
- 高く積むほど背景の色が変わる（地面 → 夕方 → 空 → 宇宙）。スクショの色が回ごとに違うのが「人に見せたくなる」の芯
- 気持ちよさは、マンガの効果（ギザギザの吹き出し・集中線・跳ねる文字）で盛る

## 参考にした実例（`factory-refs/board.md`・`factory-refs/shots/`）

- DELFONICS https://www.delfonics.com/ ：画面全部を1色で塗り、黒の極太の文字だけで組む。文字の大小の差を大きく
- POP IS YOU SAKAE https://popisyousakae.com/ ：角の丸いぷっくりした建物を積む。英字のロゴを大きく、日本語を小さく添える
- くまWEB https://kumaweb-coding.jp/ ：黒い輪郭＋ベタ塗り、ギザギザの吹き出し・集中線の勢い
- UGOKKO https://ugokko.jp/ ：下に並ぶ大きい2つのボタン（親指の届く位置）
- itch.io の stack / one-button の人気作（BURGER STACK・Cheese Tower など）：一色の背景に積んだ物だけ。スコアを絵の一部として一番上に

- 背景の色は `src/lib/color.ts` の `SKY_STOPS`。間は色相をまわして混ぜる（RGB で混ぜると濁る）。墨とクリームのどちらでも 4.5:1 に届かない途中の色は、少し暗くする（`skyAt`）
- 背景の上の文字は `inkOn(背景)` で墨かクリームを選ぶ。直接 hex を書かない
- 積み木の色は `BLOCK_COLORS` を順に使う（0段目の土台はクリーム）。積み木には必ず墨の輪郭

## 文字

- 書体：端末の極太ゴシック（`src/draw.ts` の `JP_FONT`：Hiragino Sans → Noto Sans JP → Yu Gothic → Meiryo）。太さは全部 900。英字のロゴは `LATIN_FONT`（Arial Black が先）。外のフォントは読み込まない
- スコアの数字だけは自作の「積み木の数字」（`src/digits.ts`。3×5 マスの角丸の四角、クリーム＋墨の輪郭＋下に影）
- 大きさ（スマホ 390px のとき）

| 所 | 大きさ |
| --- | --- |
| 遊ぶ間のスコア | 積み木の数字、1マス `min(舞台の幅×0.052, 24px)` |
| 結果のスコア | 積み木の数字、1マス `min(幅×0.075, 高さ×0.032)` |
| 称号 | 30px（シールの幅に収まるまで縮める） |
| 「ピタッ！」の吹き出し | 34px、クリームの文字に墨のふち 9px |
| 終わりの吹き出し（タイムアップ！・落っこちた！） | 40px |
| タイトルのひとこと・最初の案内 | 22〜24px |
| ボタン | 18px |
| 説明・記録・時計 | 14〜16px（14px より小さくしない） |

- 行は1行ずつ置く（折り返さない）。長い文は `fitSize` で幅に収める

## 画面の組み方

- 縦の1列（舞台）。幅は `min(画面の幅, max(320, 高さ×0.62))`、真ん中に置く。スマホは画面幅いっぱい、PC は中央に縦長
- PC で左右に余白があるとき：大きい英字「TAP STACK」「RUSH!!」を縦に、文字の色で不透明度 0.14。左下に操作の案内（15px）
- 世界の1単位 = `min(舞台の幅/400, 高さ/760)` px。積み木は幅 220・高さ 26 単位
- 地面の線は高さの 80%。地面より下は墨のベタ
- 遊ぶ間、動く積み木の下の辺が高さの 44% に来るようにカメラが上がる

### タイトル（`/`）

- レモンの背景＋放射の帯（白、不透明度 0.28、22本、ゆっくり回る）。帯の中心は高さの 20%
- ロゴ：3枚のシール「TAP」（ピンク・幅 56%）「STACK」（クリーム・82%）「RUSH」（水色・70%）を少しずらして積む。右上にコーラルのギザギザ「30秒 勝負！」
- ひとこと「止めて、重ねて、空まで積め。」、その下に説明2行（15px）
- 見本の塔（6段、少しずつずれる）と、その上で行き来する積み木
- 地面（墨）の中に「タップでスタート」（クリーム 26px、脈打つ）と「ベスト ◯階 ・ スペースキーでも遊べます」（14px）

### 遊ぶ（`/?scene=play` で途中から開ける）

- 一番上：時計のバー（高さ 16px・角丸、残りの割合だけ文字の色で塗る、中に「◯秒」）。右に音のボタン
- その下にスコア（積み木の数字）と「階 ・ ◯m」。2連続以上のピッタリで、右にピンクのギザギザ「×◯」
- 最初の2段だけ、高さの 33% に「重なった瞬間にタップ！」と下向きの三角
- 雲（クリーム）は 4階くらいから出て、夜に近づくと消える。星は 22階くらいから

### 結果（`/?scene=result` で見本を開ける）

上から順に：

1. 終わった理由のシール（墨の地にクリームの文字「タイムアップ！」か「落っこちた！」、少し傾ける）
2. スコア（積み木の数字）＋「階 ・ 高さ ◯m」（20px）。ベストを超えたら右に山吹のギザギザ「ベスト 更新！」
3. その回に積んだ塔を、そのままの形と色で縮めて描く（記念碑）
4. 称号のシール（クリーム、幅 `min(舞台-36, 420)`・高さ 92・角丸 16・影 6px・-1.5°）。左上にコーラルの札「称号」。中に称号（30px）とひとこと（15px）
5. 記録「ピタッ ◯回 ・ 最大 ◯連続 ・ ベスト ◯階」（14px）
6. ボタン2つ（下から 44px、高さ 60px、間 12px）：左「結果をシェア」（クリーム）、右「もう一回」（墨、幅 1.25 倍）
7. 一番下に「TAP STACK RUSH ・ ドメイン」（14px）。スクショに名前が残る

- 背景はその回の高さの色。放射の帯は明るい背景なら白 0.28、暗い背景ならクリーム 0.08

## 部品の形

- ボタン（DOM）：角丸 18px、墨の輪郭 3px、下に墨の影 6px。押すと 4px 沈む。フォーカスはクリーム 3px＋墨 4px の二重の輪
- 音のボタン：48×48px、角丸 14px、クリームの地に墨のスピーカーの絵。右上（安全域の内側）
- シール：角丸の板＋墨の輪郭＋下にずらした墨の影（`drawSticker`）
- ギザギザの吹き出し：とげ 12〜18 本、縦を 0.72 倍につぶす、下に墨の影（`drawBurst`）
- 積み木：角丸 6、上面にうすい色の帯、下 4.5 単位に濃い色、墨の輪郭 2.4 単位（`drawSlab`）
- お知らせ（コピーしました など）：墨の地にクリームの文字、角丸 14px、ボタンの上に 2.2 秒

## 動き

- 置いた瞬間：一番上の積み木が 0.14 秒つぶれて戻る（縦 -28%・横 +7%）。塔が 4 単位沈んで戻る。スコアの数字が跳ねる
- ピッタリ：クリームの輪が広がる（3連続から2重）、白い光（不透明度 0.13）、紙吹雪の粒、0.045 秒止まる、「ピタッ！」（5連続から「神ピタッ！」）が跳ねて出る、スマホは振動 12ms。3連続から集中線
- ずれた：はみ出した分が切れて、回りながら落ちる。切れた幅に応じて画面が揺れる（3〜13px）
- 外れ・時間切れ：ゆっくり（0.55 倍）になり、真ん中にピンクのギザギザの吹き出し。1.25 秒で結果へ
- 結果：数字 → 塔が下から積み上がる → 称号のシールが少し大きい所から戻る → 記録 → ボタンが下から跳ねて出る
- 残り5秒：時計の音、バーが赤く点滅
- `prefers-reduced-motion`：揺れ・白い光・集中線・つぶれ・跳ね・帯の回転・脈打ちを止める。粒は 1/3 に。結果の出方は一度に

## 音（Web Audio、外のファイルなし）

- 最初のタップ・キーで鳴らし始める。音のボタンと M キーで消せる（覚えておく）
- ピッタリは5音階で、連続するほど上がる。ずれは低い「コトン」。外れは下がる音。残り5秒は時計の音

## 文言

- タイトル：「止めて、重ねて、空まで積め。」「重なった瞬間にタップ。ずれた分は切れて落ちる。」「ピッタリで +1秒。」「タップでスタート」
- 称号は `src/lib/result.ts`（高さの段階＋その回の特徴の頭書き）。ひとことも同じ所
- 共有の文：「TAP STACK RUSH で ◯階（◯m）積んだ！／称号「◯」／ひとこと／URL」

## 写真

- 使わない。全部 canvas で描く

## 避けること

- グラデーションの面・ぼかし・ガラス風・ネオンの光（前作と被る、ポスターらしさが消える）
- 輪郭の無い形（背景の色が変わると読めなくなる）
- 墨とクリーム以外の色の文字（バッジの中の墨の文字は可）
- 画面の上の方に小さい文字をたくさん置くこと。説明は最初の2段だけ
